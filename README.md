# Drayker GitHub infrastructure

Shared public governance, contribution templates, component-contract validation and label definitions for the `draykerdk` GitHub organization.

This repository is shared GitHub infrastructure. It is not an ecosystem component and must not be listed as one on the public sites.

See [GOVERNANCE.md](./GOVERNANCE.md) for the governance horizon, the current founding-phase authority, the constitutional separation of powers and the transition criteria, and [CONTRIBUTING.md](./CONTRIBUTING.md) for the public contribution flow.
