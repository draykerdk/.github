# Drayker

Drayker is a supersystem in its founding phase, built by volunteers. It belongs to its members, with no shareholders and no profit distribution. It is building civilizational infrastructure in which people keep creating, discovering and learning alongside intelligence that carries the rest — and where what gets produced expands common capacity instead of concentrating in an external platform.

That takes a **method** for composing work, **Dk** as distributed intelligence, **Dknowledge** as distributed memory, **PAP** as the environment where intentions become projects and applications, and an evolving **member constitution** for holding decisions and resources in common. Dk's technical name is Distributed Kernel; that describes its architecture, not the whole of what it is.

The public ecosystem contains methods, architecture proposals, documentation sites and a small number of operational publishing components. Governance is explicitly evolutionary: a founding phase under the Embassy of Drayker, exercised on GitHub; then DAF, the first distribution of that authority; then a durable member constitution in which validated functions migrate into PAP. DAF is an autonomous federation of autonomous units and a basic and primitive form of PAP, implemented now on GitHub (Phase 0): its rules, instruments and public record exist. No unit has been recorded and no assembly has been held yet. DFMP is the proposal method across all of them. A repository is not, by itself, evidence that the system or governance phase it describes has been implemented.

Drayker is under construction. Each component is at a different stage, and details can change as construction advances. This documentation is the reference for the current state of each one.

- [drayker.com](https://drayker.com). What Drayker is and how its parts fit together
- [drayker.org](https://drayker.org). Projects, documentation and contribution
- [Dknowledge](https://dknowledge.drayker.org). Public surface of Drayker's distributed memory
- [General Forum](https://forum.drayker.org). Questions and proposals without a clear repository

Research and documentation remain active, and contributions are voluntary. Whoever arrives enters through DAF, the federation in which people, teams and projects build Drayker together: bring your own group or start alone with an open function, and each delivery is recorded in the name of whoever made it. Drayker is meant to be constituted by members rather than consumed by users, but membership rules are not operational yet. Large-scale implementation depends on sufficient funding. Participation does not imply compensation.

There are open functions right now — concrete pieces of work, sized for one person, at [drayker.org/fn](https://drayker.org/fn/). Start with [CONTRIBUTING.md](../CONTRIBUTING.md). The current founding-phase authority is documented in [GOVERNANCE.md](../GOVERNANCE.md).
