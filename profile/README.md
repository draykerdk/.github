# Drayker

Drayker is working towards a way of living where people keep creating, discovering and learning alongside intelligence that carries the rest — and where what gets produced reaches the work that produced it, instead of concentrating.

That takes three things, and they are what this organization builds: a **method** for cutting problems into functions one person can finish, a **distributed system** to carry the intelligence and computing, and an **organization** designed to keep decisions and resources attached to delivered work.

The public ecosystem contains methods, architecture proposals, documentation sites and a small number of operational publishing components. A repository is not, by itself, evidence that the system it describes has been implemented.

- [drayker.com](https://drayker.com) — institutional presentation
- [drayker.org](https://drayker.org) — projects, documentation and contribution
- [Dknowledge](https://dknowledge.drayker.org) — global public knowledge base
- [General Forum](https://github.com/draykerdk/general-forum/issues) — questions and proposals without a clear repository

Research and documentation remain active, and voluntary contributions are open. Large-scale implementation depends on sufficient funding. Participation does not imply compensation.

There are open functions right now — concrete pieces of work, sized for one person, at [drayker.org/fn](https://drayker.org/fn/). Start with [CONTRIBUTING.md](../CONTRIBUTING.md). The current founding-phase authority is documented in [GOVERNANCE.md](../GOVERNANCE.md).
